# Instruções para agentes

Este repositório é uma **vitrine**: lista os projetos de Urlan Dipre e abre o
endereço em produção de cada um. Leia o `README.md` antes de mexer.

- **Não copie projeto para cá.** Código e build moram no repositório de cada
  projeto. Aqui só entra uma entrada em `projetos.json`.
- Para adicionar: `python3 scripts/vitrine.py adicionar` (veja o README). Só
  entra o que já está no ar.
- `projetos.json` é a fonte única; `index.html` e `404.html` leem dele.

## Texto de apresentação

Ao escrever a `desc` de um projeto, descreva o que ele é, para quem e o que dá
para fazer nele. Não use quantidade (perguntas, telas, categorias,
componentes), lista de itens nem histórico do trabalho: esse texto não pode
precisar de edição quando o projeto crescer.
