O site do Dr. Geraldo

Página única de apresentação para um consultório de endocrinologia em Vila Velha: abertura, credenciais, áreas de atuação, depoimentos de pacientes e contato por WhatsApp. HTML e CSS puros, sem build e sem JavaScript próprio.

É uma proposta para aprovação do cliente, não o site publicado do consultório: nome, endereço, depoimentos e credenciais ainda têm pendências de confirmação, listadas no README do projeto.
