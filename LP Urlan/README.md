# LP Urlan

Landing page pessoal da UD Labs (marca de Urlan Dipre), com apresentação do
trabalho, serviços e dois formulários de captação: briefing de projeto digital
e diagnóstico de site gratuito. Site estático, HTML/CSS/JS puro, sem build.

| Peça | |
|---|---|
| [`index.html`](index.html) | Página inicial: apresentação, serviços, prova social |
| [`briefing/`](briefing/index.html) | Formulário de briefing, grava lead numa planilha do Google via Apps Script |
| [`diagnostico/`](diagnostico/index.html) | Página de captação do diagnóstico de site gratuito |
| [`google-apps-script.gs`](google-apps-script.gs) | Script que recebe o POST do briefing e grava na planilha |
