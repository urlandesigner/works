# Contexto do Projeto

Os dados dos sites desenvolvidos pela UD Labs estão dispersos em várias propriedades do Google Analytics.

Este sistema é uma ferramenta interna e pessoal da UD Labs: usado apenas pelo dono/administrador, para centralizar a visão de Analytics de todos os sites que ele desenvolve. Não há acesso de clientes nem múltiplos usuários.

Objetivo central:
Responder rapidamente "Onde preciso olhar agora?" entre todos os sites do portfólio.

Foco do MVP:
- tráfego
- comportamento
- conversões

No futuro poderá incluir (fora do MVP):
- SEO
- uptime
- performance
- monitoramento técnico
- IA

O produto permanece interno e de usuário único em todas as fases.
