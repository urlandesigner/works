# Design System

Objetivo:
Dashboard profissional focado em leitura de dados.

Princípios:
- Alta densidade de informação
- Escaneabilidade
- Pouco ruído visual
- Hierarquia forte

## Semântica de status (Home operacional)
- Cor é reservada para estado: técnico (erro), queda, pico.
- Fora dos indicadores de status, a interface é neutra.
- A Home prioriza a varredura rápida: exceção no topo, rotina rebaixada.
