# Roadmap

O produto permanece interno e de usuário único em todas as fases, sem multiusuário e sem acesso de clientes.

## Estado atual
- MVP funcional no frontend e conectado a um projeto Supabase real
- Login, Home, Lista de Sites, Cadastro, Edição, Dashboard do Site e Configurações já implementados
- Edge Function `sync-ga4` pronta e operando com GA4 via service account
- Fluxo real de cadastro + sync inicial funcionando

## Fechamento operacional do MVP
- ativar o cron diário do Supabase para o sync incremental de 3 dias
- validar a rotina com múltiplos sites reais
- melhorar responsividade/mobile
- revisar documentação e testes básicos
