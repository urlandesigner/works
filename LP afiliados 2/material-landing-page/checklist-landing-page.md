# Checklist — Landing Page de Conversão

Use antes de publicar. Cada item marcado é uma alavanca de conversão verificada.

## Above-the-fold
- [ ] Headline de 6–12 palavras focada no resultado
- [ ] Subtítulo de 15–25 palavras explicando o como
- [ ] Imagem hero mostra o resultado/benefício, não um print do produto
- [ ] CTA primário visível sem rolar, com verbo de ação + valor
- [ ] Prova social presente (logos, contagem ou depoimento)
- [ ] Valor comunicado em até ~5 segundos

## Foco e clareza
- [ ] Apenas UM objetivo/CTA principal na página
- [ ] Sem links que dispersem (menos distração = mais conversão)
- [ ] Oferta clara: visitante entende o produto sem esforço
- [ ] Dúvidas comuns respondidas (preço, frete, garantia, devolução)

## Copy
- [ ] Benefícios em destaque, características traduzidas em ganhos
- [ ] Parágrafos de no máximo 3–4 linhas
- [ ] Subtítulos descritivos a cada ~2 parágrafos
- [ ] Título alinhado com o anúncio/fonte de tráfego (message match)

## CTA
- [ ] Alto contraste, é o elemento mais visível
- [ ] Tamanho mínimo 44px, espaço em branco ao redor
- [ ] Texto completa "Eu quero…" / primeira pessoa
- [ ] Repetido após cada seção principal
- [ ] Redutor de receio próximo ("Cancele quando quiser", "14 dias grátis")
- [ ] Ícone/seta opcional para reforçar a ação

## Formulário (se houver)
- [ ] Só campos indispensáveis (nome + e-mail no máximo)
- [ ] Coluna única
- [ ] Validação inline com mensagens claras
- [ ] Botão de envio com texto de ação ("Criar conta", não "Enviar")

## Gatilhos de persuasão (quando fizer sentido)
- [ ] Urgência / escassez
- [ ] Autoridade / prova social / dados
- [ ] Brinde ou redução de risco

## Design e estrutura
- [ ] Elemento mais importante = mais proeminente (tamanho, cor, posição)
- [ ] Sem "falso fim de página" (dicas visuais para continuar rolando)
- [ ] Ordem de seções segue o padrão de conversão

## Mobile
- [ ] CTA full-width e sticky no scroll
- [ ] Sem scroll horizontal
- [ ] Fonte mínima 16px, tap targets 48x48px
- [ ] Imagens responsivas

## Performance
- [ ] LCP < 2,5s
- [ ] Imagem hero < 200 KB, página total < 2 MB
- [ ] Lazy load abaixo da dobra
- [ ] Imagens comprimidas (checar PageSpeed Insights)

## Acessibilidade
- [ ] Contraste adequado (WCAG AA)
- [ ] Navegável por teclado
- [ ] Alvos de toque adequados

## Pós-lançamento
- [ ] Heatmap configurado
- [ ] Teste A/B planejado (headline, CTA, imagem)
- [ ] Métrica de sucesso definida (CTR / taxa de conversão)
